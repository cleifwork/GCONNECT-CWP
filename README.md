# GConnect OC200 Portal

Custom OC200 voucher portal and local remaining-time service. This branch contains the OC200 project at the repository root; the original project remains on `main`.

- [Setup and troubleshooting](SETUP-GUIDE.md)
- [Windows service setup](voucher-status-service/README.md)

Keep local credentials and certificates out of Git. Build the controller portal ZIP from static assets only; do not include the service folder or private configuration.
